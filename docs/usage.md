# Schritt für Schritt

## Erweiterung einschalten

Studio lädt die Erweiterung erst, wenn ein Benutzerdefinierter Block bearbeitet
wird. Einmal pro Browser-Tab genügt.

1. Öffnen Sie in Studio unter **Inhalt** eine Seite im **Editor**.
2. Enthält die Seite einen **Benutzerdefinierten Block** (etwa eine Tabelle
   oder einen Projektplan): Klicken Sie ihn an und dann auf **Bearbeiten**.
   Schließen Sie das Fenster wieder, ohne etwas zu ändern.
3. Enthält die Seite keinen: Fügen Sie über **Blöcke** einen
   **Benutzerdefinierten Block** ein, klicken Sie ihn an und dann auf
   **Bearbeiten**. Schließen Sie das Fenster und löschen Sie den Block wieder.
4. Setzen Sie den Cursor in einen Titel oder Absatz und öffnen Sie das
   Format-Auswahlfeld in der Toolbar. Steht dort die Gruppe
   **„MAN Typo-Skala“**, ist die Erweiterung aktiv — für alle Seiten, die Sie
   in diesem Browser-Tab öffnen.

## Eine Stufe setzen

1. Setzen Sie den Cursor in den Titel oder in den Absatz. Um mehrere Absätze
   auf einmal umzustellen, markieren Sie sie.
2. Öffnen Sie in der Toolbar das Format-Auswahlfeld (es zeigt die aktuelle
   Stufe, z. B. „Body M · 16“).
3. Wählen Sie unter **„MAN Typo-Skala“** die gewünschte Stufe. Titel bieten die
   Stufen Display 2XL bis H1, Texte H2 bis Body XS.
4. Prüfen Sie das Ergebnis: Zusatzstufen tragen oben rechts ein dunkles
   Etikett. Mit **Strg+Z** (Mac: **⌘+Z**) machen Sie die Änderung rückgängig.
5. Klicken Sie auf **Speichern**.

## Eine Zusatzstufe entfernen

1. Setzen Sie den Cursor in den Block.
2. Wählen Sie im Format-Auswahlfeld eine Stufe ohne Etikett, etwa
   **Display L**, **H1** oder **Body M**.
3. Klicken Sie auf **Speichern**.

## Regeln für die Redaktion

1. Bearbeiten Sie Seiten mit Zusatzstufen nur mit aktiver Erweiterung. Ohne
   sie sehen Sie die Stufe im Editor nicht, sie wirkt für Leser:innen aber
   weiter.
2. Setzen Sie die Stufe nach **Duplizieren** oder Kopieren neu: Die Kopie
   bekommt keine Stufe mit.
3. Vergeben Sie keine Zusatzstufe an Blöcke, auf die ein Sprunglink (Anker)
   zeigt — das Setzen ändert die Kennung des Blocks, der Link ginge ins Leere.
4. Verwenden Sie einen Titel pro Seite und gliedern Sie darunter mit H2 bis H4.

## Wenn etwas nicht funktioniert

1. Fehlt die Gruppe „MAN Typo-Skala“: Schalten Sie die Erweiterung wie oben
   beschrieben ein. Nach einem Neuladen des Browser-Tabs ist das erneut nötig.
2. Sieht die Stufe im Editor richtig aus, auf der veröffentlichten Seite aber
   nicht: Wenden Sie sich an die Studio-Administration — dann fehlt das
   Custom CSS mit der Typo-Erweiterung.
