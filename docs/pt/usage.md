# Passo a passo

## Ativar a extensão

O Studio só carrega a extensão quando um bloco personalizado está a ser editado.
Basta fazê-lo uma vez por separador do navegador.

1. No Studio, em **Conteúdo**, abra uma página no **Editor**.
2. Se a página contiver um **Bloco Personalizado** (por exemplo, uma tabela
   ou um plano de projeto): clique nele e, em seguida, em **Editar**.
   Feche a janela sem efetuar quaisquer alterações.
3. Se a página não contiver nenhum: insira, através de **Blocos**, um
   **Bloco Personalizado**, clique nele e, em seguida, em
   **Editar**. Feche a janela e elimine novamente o bloco.
4. Coloque o cursor num título ou parágrafo e abra o
   menu de formatação na barra de ferramentas. Se o grupo
   **«MAN Typo-Skala»** estiver visível, a extensão está ativa — para todas as páginas que abrir
   nesta aba do navegador.

## Definir um nível

1. Coloque o cursor no título ou no parágrafo. Para alterar vários parágrafos
   de uma só vez, selecione-os.
2. Abra o menu de formatação na barra de ferramentas (que mostra o nível atual
  , por exemplo, «Body M · 16»).
3. Selecione o nível pretendido em **«Escala tipográfica MAN»**. Os títulos oferecem os
   níveis Display 2XL a H1; os textos, H2 a Body XS.
4. Verifique o resultado: os níveis adicionais apresentam uma etiqueta escura
   no canto superior direito. Com **Ctrl+Z** (Mac: **⌘+Z**) pode anular a alteração.
5. Clique em **Guardar**.

## Remover um nível adicional

1. Coloque o cursor no bloco.
2. No campo de seleção de formato, escolha um nível sem etiqueta, como
   **H1**, **H2** ou **Body M**.
3. Clique em **Guardar**.

## Alinhar verticalmente o conteúdo das colunas

1. Clique no contentor e, em seguida, na sua barra de ferramentas, em
   **Editar contentor** (ícone da caneta).
2. No separador **Layout**, encontrará, por baixo dos botões de layout, a secção
   **«Alinhamento vertical»**. Selecione **topo**, **centro** ou **fundo** —
   isto aplica-se a todas as colunas do contentor.
3. Se quiser que uma coluna tenha um alinhamento diferente: selecione na respetiva linha (**Coluna 1**,
   **Coluna 2** …) o alinhamento pretendido. A opção **como o contentor** aplica
   novamente a configuração do contentor. Ao passar o rato por cima de uma
   linha, a coluna no editor fica com uma moldura azul.
4. O editor mostra imediatamente o alinhamento. Com **Ctrl+Z** (Mac: **⌘+Z**)
   pode anular uma alteração.
5. Clique em **Guardar**.

A alinhamento só fica visível se as colunas tiverem quantidades diferentes de conteúdo
— a coluna mais curta desloca-se então para baixo ou para o centro.

## Regras para a redação

1. Edite páginas com níveis adicionais apenas com a extensão ativa. Sem
   ela, não verá o nível no editor, mas este continua a ter efeito para os leitores:
   as leitoras.
2. Defina novamente o nível e o alinhamento após **Duplicar** ou copiar:
   a cópia não herda esses parâmetros.
3. Não atribua níveis adicionais nem alinhamento a blocos para os quais um
   link de salto (âncora) aponte — essa definição altera o identificador do bloco, pelo que
   o link deixaria de funcionar.
4. Utilize um título por página e estruture o conteúdo abaixo com H2 a H4.

## Se algo não funcionar

1. Se faltar o grupo «MAN Typo-Skala»: ative a extensão conforme descrito acima.
   Após recarregar o separador do navegador, será necessário repetir este procedimento.
2. Se faltar a secção «Alinhamento vertical» no separador **Layout**: também neste caso
   a extensão não está ativada. Clique novamente no contentor
   e reabra a caixa de diálogo.
3. Se o nível ou o alinhamento parecerem corretos no editor, mas não na
   página publicada: contacte a
   administração do Studio — nesse caso, falta o CSS personalizado atual.
