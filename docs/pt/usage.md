# Passo a passo

## Ligue a extensão

O Studio não carrega a extensão até que um bloco personalizado seja editado
. Uma vez por aba do navegador é suficiente. 

1. No Estúdio, em **Conteúdo**, abra uma página no **Editor**. 
2. A página contém um **Bloco Personalizado** (como uma tabela)
   ou um plano de projeto): Clique nele e depois clique em **Editar**. 
   Feche a janela novamente sem mudar nada. 
3. Se a página não contiver um: Adicione um
   **Custom Block**, clique nele, e depois clique
   **Edit**. Feche a janela e exclua o bloco novamente. 
4. Coloque o cursor em um título ou parágrafo e abra o
   Campo de seleção de formato na barra de ferramentas. Se o grupo
   **"MAN Typo-Scale"**, a extensão está ativa — para todas as páginas que você
   Nesta aba do navegador. 

## Dê um passo

1. Coloque o cursor no título ou parágrafo. Para mover vários parágrafos
   Imediatamente, marque-os. 
2. Abra a caixa de seleção de formato na barra de ferramentas (ela mostra o atual
   Nível, por exemplo, "Corpo M · 16“). 
3. Selecione o nível desejado em **"MAN Typer Scale"**. Os títulos oferecem o
   Os passos exibem de 2XL para H1, textos de H2 para o XS do corpo. 
4. Verifique o resultado: Passos adicionais têm um escuro no canto superior direito
   Rótulo. Use **Ctrl+Z** (Mac: **⌘+Z**) para desfazer a alteração. 
5. Clique em **Salvar**. 

## Remover um nível adicional

1. Coloque o cursor no bloco. 
2. No campo de seleção de formato, selecione um nível sem etiqueta, como
   **Exibir L**, **H1** ou **Corpo M**. 
3. Clique em **Salvar**. 

## Regras para Editores

1. Editar páginas com níveis adicionais apenas com uma extensão ativa. Nenhuma
   Você não vê o nível no editor, mas funciona para os leitores
   continua. 
2. Resetar o nível após **Duplicar** ou Copiar: A Cópia
   não ganha nenhum degrau. 
3. Não atribua um nível adicional a blocos aos quais existe um jump link (âncora)
   — ao configurá-lo, muda o identificador do bloco, o link não levaria a lugar nenhum. 
4. Use um título por página e divida abaixo dele de H2 a H4. 

## Quando algo não funciona

1. Se o grupo "MAN Typo Scale" estiver ausente: Troque a extensão como acima
   . Depois de recarregar a aba do navegador, isso é necessário novamente. 
2. O nível parece correto no editor, mas na página publicada
   not: Contato com a administração do estúdio — então o
   CSS personalizado com a extensão Typo.
